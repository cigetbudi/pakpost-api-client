# Security reporting

Please report suspected vulnerabilities privately to the project maintainer through a trusted contact channel. Do not publish session tokens, private keys, actual workspace data or exploit details in a public issue. Include the affected version, environment, reproducible steps using test data, impact and suggested remediation if known. No dedicated security contact address or support SLA is declared in this repository.

See [security model](docs/security.md), [configuration](docs/configuration.md) and [recovery](docs/backup-and-recovery.md). Keep deployments current with reviewed fixes. A passing test suite is not a security certification.
