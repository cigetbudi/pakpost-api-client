# Historical implementation notes

These documents describe earlier patches, migration steps and design proposals, not the current release. Do not run commands from this archive on an active instance. For current instructions see [installation](../installation.md), [deployment](../deployment.md) and [architecture](../architecture.md).

Legacy one-off helpers (`scripts/patches/`, `scripts/desktop/apply-relocation.sh`, `scripts/production/d5-*`, and `frontend/scripts/activate-bun.sh`) are retained for historical reference only. Do not execute them as part of a v0.1.0 installation. Phase-specific verification scripts may still be useful for targeted tests. Use the root Makefile and current deployment scripts instead.
