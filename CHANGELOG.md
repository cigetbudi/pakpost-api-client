# Changelog

## 0.1.0 — Initial REST release

Feature baseline (not a commit-by-commit chronology):

- REST workbench with local/cloud storage, collections, folders, environment and collection variables, cURL import and code generation.
- Google sign-in, workspace roles, invitations, membership removal and realtime member updates.
- Workspace envelope encryption, session revocation and authorization hardening.
- Desktop Tauri app with native HTTP, cancellation, SQLite, connection profiles, browser pairing, OS credential-vault login and native realtime fallback.
- Adaptive web/mobile layout, Light/Dark/AMOLED, command palette, pin tabs, script snippets and response analysis.
- Collection Runner with CSV/JSON iteration data and JSON/JUnit reports; extended but incomplete Postman-style scripting and JSONPath support.
- QuickJS resource limits, desktop CSP, production logging/redaction, persistent Data Protection, deployment readiness, backup utilities and read-only k6 baseline.

Known limitations: Cloud undo-delete, full JSONPath/Postman parity, granular DNS/TCP/TLS timings, signed installer distribution and auto-update are not complete. No multi-instance realtime guarantee or independent security certification. Feature-frozen; subsequent changes should be fixes and maintenance.
